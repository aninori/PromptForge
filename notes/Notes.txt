Built PromptForge, a RAG-based AI developer assistant for Coforge's claims-engine codebase, by chunking 1,840 code segments into a Chroma vector store with nomic-embed-text embeddings, layering query optimization and import-graph context expansion, and streaming responses from local Ollama LLMs (Mistral/Qwen) over SSE. Reduced prompt token consumption by ~80% versus naive whole-repo injection — saving 140K+ tokens per query session — enabling developers to get targeted bug fixes, refactor plans, and security audits in under 2 seconds with zero cloud LLM cost.
